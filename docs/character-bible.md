> 团成一团，慢慢向前。

## 身份标识

| 项 | 内容 |
| :--- | :--- |
| 物种 | Q 版萌系貉（狸猫 / 浣熊狗） |
| 定位 | 城市夜行干饭团子 · 博客与 Bot 吉祥物 |
| 比例 | 二头身，短手短腿 |
| 核心特征 | 大圆瞳、可可小眼罩、桃粉围巾、蓬松尾巴 |

## 形态规范

定稿形态，新增形象时不可改动：

- 耳朵：小而圆，趴在头顶两侧
- 眼睛：黑色大圆豆豆眼，带白色高光点
- 面罩：眼周一圈淡淡的浅褐色花纹
- 口鼻与肚皮：奶油白色
- 腮红：粉色圆晕，左右对称
- 四肢：短短的手臂收在身前，短短的小腿站立
- 尾巴：毛茸茸的短尾巴，尾尖深色
- 头身比：二头身，又大又圆的扁圆头
- 画风：粗棕色描边，贴纸卡通风格，平涂色块无渐变

新增内容只可追加动作、道具、场景，不得改动上述形态特征。
