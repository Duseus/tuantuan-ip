## 生成锚定描述（出图时必须原样包含）

```
一只Q版萌系貉（狸猫/浣熊狗）吉祥物：二头身比例，又大又圆的扁圆头，
小而圆的耳朵趴在头顶，黑色大圆豆豆眼带白色高光，眼周有淡淡的浅褐色面罩花纹，
奶油白色的小口鼻和圆肚皮，粉色圆腮红，短短的手臂收在身前，短短的小腿站着，
毛茸茸的短尾巴带深色尾尖。粗棕色描边贴纸卡通风格，平涂色块无渐变，
干净纯白背景，主体居中
```

禁止改动的形态特征：耳朵形状、豆豆眼、眼罩花纹、头身比例。
只可追加动作、道具、场景。按需追加反面约束：不要写实动物脸、不要尖耳、不要凶相、不要文字错别字。
